# 本地弹唱谱

1.3.0 在本机从原曲生成带时间的和弦参考谱，复用导入歌词、播放器及已有音频环境。原曲逐音六线谱没有纳入本版。

- 入口：score_job.py，由 App 用已有 app/audio/引擎/.venv/bin/python 启动，输出进度与完成结果，每行一个 JSON。
- 权重：weights/，五份共 28,730,939 字节，来源、固定版本及 SHA-256 在 models.json。缺失时明确失败，普通生成不下载、不联网。显式恢复命令为 python3 app/audio/乐谱/install_models.py。
- 数值组件：沿用 Torch 2.7.1、librosa 0.11.0、numpy 2.4.6。没有照抄上游安装命令升级环境。仅把推理时需要的 pydub 0.25.1 源码随附于 vendor/。
- 指法：guitar.json 来自 chords-db，使用具体和弦及转位匹配；没有合适指法时明确显示缺失。
- 内存：识别工作进程仅任务期间存在；默认对 10 分钟内选段使用苹果芯片加速的完整上下文；更长选段或加速不可用时按 10 秒块、前后各约 4 秒上下文处理概率，之后全段解码。加速异常由主程序在新进程中仅重试一次 CPU 省内存方式。播放与看谱不加载识别模型。范围为 0.2 秒至 30 分钟，不伪造逐字时间。
- 歌曲及中间 WAV 不留在本目录。FFmpeg 输入放在任务自己的临时目录，成功、失败、正常取消均清理。取消超过两秒时 App 终止该工作进程。
- 回归：app/macos/测试/乐谱后端检查.py 使用现有音频 Python 执行；原生入口与验证范围见 docs/verification/score-1.3.0.md。
- 权重、环境和个人音频不进 Git。没有验证其他电脑首次安装或公开分发，来源及本轮改动见 THIRD_PARTY.md。
