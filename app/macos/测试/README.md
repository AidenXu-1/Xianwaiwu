# 本机检查

在项目根目录执行：

```sh
bash tools/check-local.command
```

该入口使用系统 Swift 编译器，核对资料保存、歌词文档解析、乐谱数据与 PDF/ChordPro、鼓点时序和系统离线音频输出。临时文件放在系统临时目录，结束时清理；不使用日常资料库。

该便捷入口显式跳过个人参考文件，使用可随源码重现的输入。直接运行 LyricsRegression 时，歌词检查还包含可选的开发者参考 LRC。存在调用者 Downloads 中的《入海歌词.lrc》，或明确设置 `XIANWAIWU_TEST_LYRICS` 时，会额外检查该参考文件的 84 个时间项；没有该文件时明确跳过这两项，其余自建 LRC 与真实 Word 检查仍执行。歌曲和歌词文件不随仓库提供。

音频环境准备完成后，可运行不依赖个人歌曲的乐谱后端边界检查：

```sh
app/audio/引擎/.venv/bin/python -B app/macos/测试/乐谱后端检查.py
```

App 的完整分离、歌词和界面验证另有显式 `--verify` / `--verify-score` 入口，必须使用独立 `XIANWAIWU_DATA`；部分历史检查需要开发者保留的真实分轨夹具，仓库不再分发这些音频。完整本机检查记录与对外安装验证分别说明，不把缺失夹具当作已验证。

## 1.3.7 本机验证记录

2026-11-09，整理后的源码目录通过上方 175 项便捷检查，并在开发者当前的 Apple 芯片 Mac 上成功构建。新构建另通过 38 项真实窗口检查，覆盖普通与长歌名、两档窗口大小、乐谱与音轨切换。窗口检查复用了已有音频环境。

同轮还在独立资料库完成 303 项真实音频流程及跨进程恢复检查，以及 189 项资料、歌词、乐谱、鼓点与后端检查。这些结果限定于本机既有环境；其他电脑的首次依赖安装、独立安装包、签名公证仍未验收。不同入口存在重叠检查，不以相加数量代表独立场景数。
