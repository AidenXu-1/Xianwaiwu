# 弦外屋使用说明

## 分离与试听

1. 拖入一首本地歌曲，创建项目。
2. 在「原曲」页选择整首或片段。可以拖动波形、调整两端，或输入开始和结束时间，点击「完成」。
3. 选择「人声与伴奏」「主唱、和声、伴奏」或「音乐六轨」，开始分离。
4. 在「分离结果」中试听。S 可同时独奏多轨，扬声器按钮控制各轨开关。
5. 点击「导出音轨」，选择音轨、格式与保存位置。

鼠标在波形上移动时会显示定位线和时间。分离结果页只负责结果试听与导出；需要调整下一次处理范围时返回「原曲」，已有结果保留。

## 导入歌词

点击歌名旁「歌词」，导入或粘贴自带完整时间的内容。支持 LRC、TXT、Markdown、DOC/DOCX。文件扩展名只决定读取方式，能否同步由实际时间内容判断。

```text
[00:16.430]第一句歌词
[00:20.050]第二句歌词
```

可以编辑、整体提前或延后 0.1 秒，导出为 LRC。没有时间、时间残缺、倒序、超过歌曲时长或无法读取时，会给出提示，失败不替换已有歌词。

## 弹唱练习

点击歌名旁「乐谱」，使用原曲页已经确认的范围生成参考谱，无需先分轨。

- 当前和弦格逐渐填色，每句各自走满。
- 同一和弦延续到下一句时，提示提前接在上一句最后一个和弦格之后。
- 同一句内谱面静止，换句平滑切换；手动翻谱暂停跟随，重新勾选可回到当前句。
- 右侧显示吉他指法，可切换把位；变调夹、速度与升降调用于练习。
- 「循环这句」设置 A/B 范围，按播放开始循环练习。
- 点击和弦定位，点击铅笔修改原调和弦或切换时间。
- 鼓点声默认关闭，可以按需打开；暂停、跳转与循环同步，返回音轨时停止。

左上「重新识别」会先确认，生成成功后才替换原谱，失败或取消时保留原谱。右侧「返回音轨」继续原来的音轨操作。

## 保存乐谱

右上角「导出乐谱」提供 PDF、ChordPro 和复制带时间的和弦歌词。PDF 中的中文文字可以搜索。只有逐句歌词时间时，和弦按时间排列，不代表已经逐字对齐。

## 当前边界

音乐六轨仍属于实验功能；分离结果可能残留其他声部。自动和弦是可校正的参考，不保证等同于原曲准确编配。目前没有原曲逐音六线谱、扫弦编配、其他乐器专用指法或自动歌词生成。
